# Data Notes

This dataset contains estimated travel costs from Newark, NJ to various New Jersey destinations for spring break trips.

## Source

The data is a starter dataset with approximate estimated costs. It is not based on real-time data but on general averages for planning purposes.

## Caveats and Limitations

- Costs are estimates and may not reflect current market prices.
- Travel costs assume round-trip transportation (e.g., bus or train).
- Lodging costs are average nightly rates.
- Food costs are daily averages.
- Activity costs are fixed estimates for typical spring break activities.
- No consideration for seasonal variations, promotions, or personal preferences.

## Future Improvements

Future versions of this app could integrate live data from hotel APIs (e.g., Booking.com or Expedia) for more accurate lodging costs, or use Google Maps API for real-time travel costs.
